# 모집/지원 기능 — 기획 확인 요청 사항

> 현재 개발 중 기획서에서 명확하지 않거나, 기획 판단이 필요한 사항을 정리했습니다.
> 각 항목의 **"결정이 필요한 부분"** 을 확인해주세요.

---

## ~~1. 지원서 수정 가능 기간~~ (결정 완료)

> **결정:** 지원서 수정은 **지원 마감 시점까지** 가능. 마감 이후 수정 버튼 비활성화.
> 기존의 복잡한 수정 기간 설정(제출일/배포일 기준 N일) 방식은 제거.

---

## 2. 공고 수정이 가능한 시점

### 기획서 내용

- 버전관리 하지 않음 (최종 수정본만 유지)
- 질문 항목 추가/삭제만 가능 (기존 항목 내용 수정은 불가)
- 2차 면접 여부 변경 가능
- 제목/내용 수정 가능
- 수정 시 기존 지원자에게 알림 발송

### 결정이 필요한 부분

- [ ] **언제부터** 수정 가능한가요? — 모집 시작(공개) 이후부터? 작성 중(임시저장)일 때도?
- [ ] **언제까지** 수정 가능한가요? — 지원 마감일까지? 모집 종료까지? 추가합격 기간 중에도?

> 참고: "기존 지원자에게 알림 발송"이라는 규칙이 있으므로, 최소한 모집 중(지원자가 존재하는 상태)에서의 수정은 가능해야 할 것으로 보입니다.

---

## 3. 동시 편집 방지

### 기획서 내용

- 공고를 수정하는 중에 다른 운영진이 접근하면 차단
- 수정 화면을 벗어나거나 5분간 조작이 없으면 잠금 해제

### 결정이 필요한 부분

- [ ] 잠금 해제 방식: 사용자가 브라우저를 닫거나 페이지를 벗어났을 때 **즉시 해제**가 필요한지, 아니면 **최대 5분 대기 후 자동 해제**로 충분한지?
- [ ] 적용 범위: 모집 공고만 해당하는지? 소개페이지, 지원서 양식 등도 동시 편집 방지가 필요한지?

---

## 4. 공고 수정 시 기존 지원자 알림

### 기획서 내용

- 공고가 수정되면 기존 지원자에게 알림 발송

### 현재 상태

- 알림 시스템 자체가 아직 개발되지 않은 상태
- 알림 시스템(푸시 알림, 알림톡, 문자, 앱 내 알림 등) 구축 후 연동 예정

### 결정이 필요한 부분

- [ ] 알림 채널 우선순위: 앱 푸시 / 카카오 알림톡 / 문자 중 어떤 것을 사용할지?
- [ ] 알림 시스템 전체 기획 일정에 맞춰 추후 반영 예정 — 일정 확인 필요

---

## 5. 임시저장 지원서 — 마감일 이후 자동 삭제

### 기획서 내용

- 임시저장된 지원서는 지원 마감일까지 보존
- 마감일이 지나면 자동으로 삭제(정리)

### 현재 상태

- 자동 삭제를 수행하는 배치 작업이 아직 미구현

### 결정이 필요한 부분

- [ ] 마감 후 즉시 삭제할지, 일정 유예 기간(예: 마감 후 7일)을 둘지?

---

## 6. 추가합격 기간 만료 후 자동 종료

### 기획서 내용

- 합격예비자의 추가합격 기간(1~14일)이 만료되면 자동으로 모집을 최종 종료

### 현재 상태

- 자동 종료를 수행하는 배치 작업이 아직 미구현

### 결정이 필요한 부분

- [ ] 추가합격 기간이 끝났을 때, 합격하지 못한 **합격예비자(대기자)** 는 어떻게 처리하나요?
  - **불합격으로 자동 전환**할지?
  - **별도 상태(기간 만료)** 로 남겨둘지?
  - 해당 지원자에게 **결과 알림**을 보낼지?

---

## 7. 지원서 응답 PDF 다운로드

### 기획서 내용

- 지원서 응답을 PDF로 다운로드할 수 있음
- 다운로드한 PDF를 개인 자료실에 업로드하여 보관 가능

### 현재 상태

- PDF 생성 기능 미구현
- 개인 자료실 기능 미구현

### 결정이 필요한 부분

- [ ] PDF에 포함할 내용 범위: 지원자 정보 + 모든 응답? 첨부파일 포함 여부?
- [ ] PDF 디자인/레이아웃에 대한 기획이 있는지?

---

## 8. 탈퇴 유저의 지원서 응답 삭제

### 기획서 내용

- 탈퇴한 유저의 게시물/댓글은 유지하되 이름을 "(알 수 없음)"으로 표시
- 단, **지원서 응답은 삭제**

### 결정이 필요한 부분

- [ ] 삭제 시점: 탈퇴 즉시 삭제할지, 탈퇴 유예 기간(예: 1주일) 이후 삭제할지?
- [ ] 동아리 운영진 입장에서 지원서 응답이 사라지면 선발 과정에 영향이 있을 수 있음 — 모집 진행 중인 경우 예외 처리가 필요한지?

---

## 9. 데이터 보관 — CSV 자료실 저장

### 기획서 내용

- 모집 종료 시 지원 데이터를 CSV 파일로 자료실에 저장 가능
- 저장 정책을 동아리별로 설정 가능: **자동보관** / **미보관** / **매번 선택**

### 현재 상태

- 자료실 기능 미구현
- CSV 변환 기능 미구현

### 결정이 필요한 부분

- [ ] CSV에 포함할 데이터 항목: 지원자 이름, 응답 전체, 합격 여부 등 — 구체적 범위?
- [ ] "매번 선택" 시 UI 흐름: 모집 종료 버튼을 누르면 팝업으로 묻는 형태?
