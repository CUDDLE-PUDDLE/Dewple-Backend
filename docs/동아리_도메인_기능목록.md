## 1. 생성/조회/수정

| # | 기능명 | 주체 | 설명 | 상태 |
|---|--------|------|------|:----:|
| 1-1 | 동아리 생성 | 회원 | 이름(50자, 욕설필터)/본인인증필수여부/카테고리(1~3개)/지역/활동방식. 회장 동시 운영 최대 5개 (승계로 인한 초과 허용) | ✅ |
| 1-2 | 동아리 목록 조회 | 회원/비회원 | 필터(본인인증/모집중/카테고리/지역/활동방식), 정렬(부원+좋아요 합산순) | ✅ |
| 1-3 | 동아리 단건 조회 | 회원/비회원 | 동아리 기본 정보 + 소개페이지 | ✅ |
| 1-4 | 동아리 정보 수정 | 운영진 (3번 권한) | 카테고리/지역/활동방식 등 변경 | ✅ |
| 1-5 | 동아리 설정 변경 | 운영진 (3번 권한) | 본인인증 필수/연령대/성별 태그. 활성 공고 있을 때 변경 불가 | ✅ |
| 1-6 | 동아리 삭제 | 운영진 (11번 권한) | 권한자 전원 동의. 1일 유예 → hard delete | ✅ |
| 1-7 | 동아리 삭제 상세 처리 | 시스템 | 유예 중 활성 공고 비활성화/취소 시 복원. 지원자 알림 발송 | ❌ |
| 1-8 | 회장 장기 미접속 처리 | 시스템 | 1년 미접속 시 한 달/일주일 전 알림 → 승계 또는 삭제 | ❌ |

|---|--------|------|------|:----:|
| 3-1 | 회원 목록 조회 | 동아리 회원 | GUEST/MEMBER/GRADUATED/KICKED 상태별 조회. 부원끼리 열람 가능 | ✅ |

| 3-7 | 회원 탈퇴 알림 | 시스템 | 회원 탈퇴 시 회원관리(9번) 권한 운영진에게 알림 | ❌ |
