- 모집&지원
    - 모집공고 조회수는 5초 이상 페이지에 머물러야 조회수 1 상승
    - 모집 공고 생성
        - 임시저장 가능
        - “지난 모집 공고 불러오기” 기능
            - 사용하면 지난 모집의 공고, 지원서에서 사용했던 컴포넌트들이 전부 순서대로 불러와짐 (공고와 지원서 자동 구성)
        - 제목, 설명 (필수)
        - 기수(0기 또는 1기 부터 auto increase)
        - 모집할 “부서 or 포지션”
            - 동아리 별로 입력할 수 있도록. 여러 개 입력 가능
            - 예시)
              운영팀, 리서치팀, 개발팀
              기타, 베이스, 보컬
            - 부서 별 모집 인원 설정
        - "모임" 기간 설정("모임" 종료일 설정)
        - 지원 마감일 설정
        - 1차 합격 공고일 설정
        - 2차 면접 여부 → Boolean
        - 임시저장 가능
        - 공고생성 시, 공고 컴포넌트를 폼 형태로 조립
            - 공고 컴포넌트는 (제목 이미지 텍스트) 가 한 세트로 구성
            - 텍스트 값을 제외하면 필수 아님, 텍스트 값은 필수
        - 지원서 양식
            - 생성
                - 최근 양식 불러오기 가능
                - 지원 컴포넌트를 폼 형태로 조립
                    - 생성 시 필수 입력 여부, 글자 여부
                    - 업로드 파일 크기 제한은 100mb까지,
                    - 컴포넌트 종류
                        - 다지선다 컴포넌트
                        - 텍스트 입력(글자수 제한 가능) 컴포넌트
                            - 줄바꿈 허용
                        - 파일 업로드 컴포넌트
                        - when2meet 컴포넌트
                            - 폼 만드는 사람은 여기서 선택 가능한 시간 pool을 설정
                            - 입력하는 사람은 선택 가능한 시간 중에 자신이 참여 가능한 시간을 선택
                        - 달력 컴포넌트 (날짜, 기간만 선택가능. 시간은 선택불가)
                            - 단일 날짜/기간 모두 가능
                            - start/end 필수
                    - 지원서 작성이 완료되면 해당 지원서의 컴포넌트들은(각 컴포넌트의 질문, 종류, 설명, 이미지 정보) 저장되어 재사용 가능
                - 2차 면접 여부가 참일 경우
                    - 지원서 생성 시에 면접 날짜 컴포넌트가 자동 생성됨(when2meet 컴포넌트, 필수 입력, 삭제 불가)
                    - 이 경우 운영진이 지원자를 합격 처리할 때 해당 지원자의 면접 시간을 통보 가능하게 함
                - “부서 or 포지션”이 여러 개인 경우
                    - 부서 선택 컴포넌트가 자동 추가된 상태로 폼이 만들어짐(다지선다 컴포넌트, 필수 입력, 삭제불가)
                - 지원서까지 다 작성했으면 모집 공고 올리기 가능
    - 모집공고 작성완료, 지원서 작성완료는 별개 (모집공고 내의 지원서를 작성완료해야 모집공고 작성 완료도 가능)
    - 지원자 리스트(지원서 응답)
        - 지원자 프로필을 확인할 수 있음
            - 기본 정보, ["모임" 이력]
        - UI는 구글 스프레드 시트(좌우 스크롤 가능) 인데, 우측에 sticky 버튼 있는 느낌
        - 지원자 리스트에서 유저 합격/불합격 여부 선택 가능
            - 설정한 부서 별 모집 인원보다 많은 인원 합격 가능
            - 합격 공고일까지 운영진이 합격처리 안해도 지원서 리스트에서는 합격/불합격 선택 가능(지연 발표 가능)
            - 2차 면접 여부가 참일 경우
                - 지원서 생성 시에 면접 날짜 컴포넌트가 자동 생성됨(when2meet 컴포넌트, 필수 입력)
                - 이 경우 운영진이 지원자를 합격 처리할 때 해당 지원자의 면접 시간을 통보 가능하게 함
                - 면접 시간을 유저가 “확정” 또는 “변경 요청” 할 수 있음
                    - 변경요청 시 운영진과 채팅방 열어줌. 이 채팅방에는 “변경 요청”한 지원자와, 문의 답변 권한을 가진 운영진들이 있음
            - 운영진이 합격, 불합격을 선택하면 유저에게 알림톡(또는 푸시 알림)이 전달됨
            - 지원자는 합격 시 가입, 반려 선택 가능 (1일 내 가입, 반려 선택 안하면 합격 취소됨) → 유저 상태가 “REJECT”
            - 지원자가 가입 선택 시 해당 동아리의 회원으로 등록됨
    - 모집 공고 삭제
        - 삭제해도 이전 모집 공고 불러오기를 통해 불러오기는 가능
    - 모집 공고 수정
        - 공고/지원서는 “게시 시점의 버전(version)”이 생기고
        - 지원자는 특정 버전에 제출
        - 운영진이 수정하면 새 버전이 생기며, 기존 제출은 기존 버전에 매핑
        - 올린 공고 제목, 공고 내용은 수정 가능
        - 지원서 양식에는 컴포넌트 추가, 컴포넌트 내 설정값 변경 가능
            - 수정/삭제 중에 지원자가 작성/제출하면 지원서가 수정되었다고 해야함. (바뀐 지원서를 보여주거나(지원서가 수정된 경우), 동아리 소개페이지로 돌아가야함(지원서가 삭제된 경우))
    - 이전 모집 공고, 지원서는 가장 최근 1개만 저장됨.
